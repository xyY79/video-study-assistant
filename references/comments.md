# 评论区知识筛选

使用双排序采样输出，不能把热度、点赞、评论条数当知识价值。样本不是评论区全体；上游每个顶层最多附带3条回复，未提供父ID；不得重建不存在的楼中楼关系。仅凭文字不判断图片含义。报告实际返回数量、去重、接口失败和样本限制。多分P共享BV评论时只抓一次，不重复计数。

逐批处理所有样本，先排除纯表情、广告、无内容赞同、重复主讲观点等。短评论若有关键纠错或资源仍保留；长评论不是天然高价值。点赞数仅附属展示，不参与入选分数。

对每个候选分别给出0至5的增量、论证、相关、实践与批判价值，权重30/25/20/15/10。评分只用于辅助，至少有明确新增事实/方法/反例/论据/资源或适用条件，并与视频主题相关才入选。保留低赞、有证据的少数派；相似观点聚类后保留独立证据与不同限定。记录每个评论ID的入选或剔除理由，禁止用固定条数凑结果。

交付优先按补充、实质反驳、纠错、经验案例、学习资源归类。每条附原始rpid、简短原文证据及与主讲内容的关系；未经核验的陈述标为评论者观点，不能当事实。把主讲、评论和编辑推论分开。必要时用授权的公开来源核实具体事实。无有效内容时明确空结果；采样失败不能说没有好评论。

回归示例（虚构）：2500赞“太真实了”应淘汰；0赞“买断制与长期运营制收入机制不同，因此不能套同一留存逻辑”应进入实质性审查。短评论“这里单位应为kPa”也应检查，不能因长度被丢弃。
